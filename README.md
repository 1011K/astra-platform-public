# ASTRA

ASTRA is an independent equity research platform for NSE/BSE listed companies, built by Krishiv Ramchandani.

> **Status: private source, public overview only.** This repository contains no code, data or methodology. Nothing here is investment advice.

## What it does

- Company and sector analysis: statement processing, filing checks, sector comparison.
- Valuation and modelling: three-statement forecasts, FCFF DCF, residual income, sum-of-the-parts, comparable companies, sensitivity analysis.
- Research outputs: source-traceable Excel and PDF reports.
- Market and risk context: equity screening, technical indicators, portfolio risk, derivatives analytics.
